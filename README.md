# fairness-adversarial-debiasing-analysis
A fairness-aware machine learning pipeline on the Adult dataset using adversarial debiasing, comparing baseline and debiased models with balanced accuracy and equal opportunity difference.

tensorflow: Session-based model training with adversarial debiasing
aif360: Adult dataset preprocessing, AdversarialDebiasing, and fairness metrics
scikit-learn: MaxAbsScaler feature scaling
